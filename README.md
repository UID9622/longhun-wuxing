### ⚖️ 指令① · 五行强度权重计分系统

**核心升级：** 同一五行属性，天干年柱 ≠ 地支日柱，位置不同 → 权重不同。

| **柱位** | **天干权重** | **地支权重** | **说明** |
| --- | --- | --- | --- |
| 年柱 | 1.0× | 0.8× | 祖辈根基·影响远但衰减 |
| 月柱 | 1.5× | 1.2× | 父母令·最影响当下运势 |
| 日柱 | 2.0× | 1.6× | 本命主柱·权重最高 |
| 时柱 | 1.2× | 1.0× | 子女晚运·影响未来 |

```python
位置权重表 = {
    "年柱": {"天干": 1.0, "地支": 0.8},
    "月柱": {"天干": 1.5, "地支": 1.2},
    "日柱": {"天干": 2.0, "地支": 1.6},
    "时柱": {"天干": 1.2, "地支": 1.0},
}

def 计算五行强度(四柱):
    得分 = {"金": 0.0, "木": 0.0, "水": 0.0, "火": 0.0, "土": 0.0}

        if 干支["天干"] in 天干五行表:

        if 干支["地支"] in 地支五行表:
            得分[地支五行表[干支["地支"]]] += 权重["地支"]
    # ... 计算均衡指数、缺失等
    return {"五行得分": 得分, "最强": ..., "最弱": ..., "均衡指数": ..., "缺失五行": ...}
```

### 🔗 指令② · 五行动态链路分析

| **关系类型** | **含义** | **系统映射** |
| --- | --- | --- |
| 相生（A→B） | A促进B增强 | 模块赋能·协作 |
| 相克（A⇒B） | A制约B消耗 | 熔断·限制 |
| 相泄（B→A反向） | A被B反向消耗 | 资源过度输出 |
| 相耗（B⇒A） | A被B克·双向损耗 | 系统冲突·高消耗 |
| 比和（A↔A） | 同五行叠加 | 同模块协同 |

```python
def 分析五行关系(A, B):
    if A == B: return "比和", f"{A}遇{B}·同类叠加·力量加倍"
    if 五行相生.get(A) == B: return "相生", f"{A}生{B}·{A}为源·{B}得增强"
    if 五行相克.get(A) == B: return "相克", f"{A}克{B}·{B}受制约·注意"
    if 五行相生.get(B) == A: return "相泄", f"{B}生{A}反向·{A}被泄耗·消耗自身"
    if 五行相克.get(B) == A: return "相耗", f"{B}克{A}·{A}受压·高消耗"
    return "无关", f"{A}与{B}无直接生克"
```

## 🐉 CNSH 龍魂文化算法流场压缩核 v3.0

**一句话：** 把任何输入压成一个可路由、可审计、可视化、可归档的「流场节点」。

### 1｜最终压缩公式

```
龍魂节点 = 输入 × 数字根 × 五行 × 生克链 × 三才权重 × DNA × 三色审计
```

```python
Node = Flow(input)

```

### 2｜唯一主流程

1. **统一输入**（文字/图像/HTML/代码/页面/对话/规则/灵感）→ `RAW_INPUT`
2. **算数字根** `dr`（无数字→0；有数字→反复相加到一位数）
3. **数字根定五行** `dr → 五行`
4. **三色闸门**：`dr∈{3,9}→🔴`，`dr=6→🟡`，其余 `🟢`
5. **五行生克**：相生 = 可接力；相克 = 需审计
6. **三才赋值**：天=0.35，地=0.15，人=0.50（人场不可低于0.34）
7. **生成节点 JSON**
